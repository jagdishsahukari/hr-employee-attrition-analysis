# HR Employee Attrition Analysis

## Project Overview

This project analyzes employee attrition to explore workforce trends and identify employee characteristics associated with leaving an organization.

Python is used for data cleaning and exploratory data analysis (EDA), SQL for querying and analysis, and Power BI for dashboard development and visualization.

## Project Objectives

- Analyze overall employee attrition.
- Explore attrition patterns across departments and job roles.
- Examine relationships between attrition and employee characteristics.
- Identify workforce trends that can support data-informed HR discussions.

## Tools and Technologies

- **Python:** Pandas, NumPy, Matplotlib, Seaborn
- **SQL:** Data querying, filtering, aggregation, and analysis
- **Power BI:** Dashboard development and visualization
- **Jupyter Notebook:** Python analysis and documentation

## Dataset

- **Rows:** 1,470
- **Columns:** 35
- **Format:** CSV

The dataset includes employee information such as age, department, job role, monthly income, job satisfaction, overtime, and attrition status.

See the `data/` folder for dataset documentation. The dataset source and applicable usage terms should be verified before redistributing it publicly.

## Project Workflow

1. **Data Understanding:** Review the dataset structure and data quality.
2. **Exploratory Data Analysis:** Examine employee characteristics and attrition patterns using Python.
3. **SQL Analysis:** Query the data to investigate workforce trends.
4. **Dashboard Development:** Visualize relevant metrics and patterns using Power BI.
5. **Insights and Recommendations:** Interpret verified results to support data-informed HR discussions.

## Key Findings

- **Overall Attrition:** 237 out of 1,470 employees left the organization, resulting in an overall attrition rate of approximately **16.12%**.
- **Workforce Analysis:** The dataset includes employee demographics, departments, job roles, compensation, job satisfaction, overtime, and other workforce characteristics.
- **Attrition Patterns:** The analysis examines how employee attrition varies across workforce groups and job-related factors.
- **Dashboard Insights:** The Power BI dashboard presents workforce metrics and attrition patterns to support easier interpretation of the analysis.

## Recommendations

- **Monitor Attrition:** Track the overall attrition rate regularly to identify changes in workforce retention.
- **Review High-Attrition Groups:** Use department and job-role analysis to identify groups that may need further investigation.
- **Evaluate Workload and Satisfaction:** Review overtime, job satisfaction, and work-life balance patterns to identify potential areas for improvement.
- **Assess Compensation Patterns:** Compare compensation across job roles and employee groups alongside observed attrition patterns.
- **Use Evidence-Based Decisions:** Validate patterns using Python, SQL, and Power BI results before making HR decisions. Observed relationships should not be treated as proof of causation.
