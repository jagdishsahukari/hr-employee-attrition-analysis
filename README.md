# HR Employee Attrition Analysis

## Project Overview

This project analyzes employee attrition to explore workforce trends and identify factors associated with employees leaving an organization.

The analysis uses Python for data cleaning and exploratory data analysis (EDA), SQL for querying and analyzing data, and Power BI for dashboard development and visualization.

## Project Objectives

- Analyze overall employee attrition.
- Explore attrition patterns across departments and job roles.
- Examine relationships between attrition and employee characteristics.
- Identify workforce trends that may help support data-informed HR decisions.

## Tools and Technologies

- **Python:** Pandas, NumPy, Matplotlib, Seaborn
- **SQL:** Data querying, filtering, aggregation, and analysis
- **Power BI:** Interactive dashboard and data visualization

## Dataset

- **Rows:** 1,470
- **Columns:** 35
- **Format:** CSV

The dataset contains employee information such as age, department, job role, monthly income, job satisfaction, overtime, and attrition status.

See the `data/` folder for dataset documentation.

## Project Structure
