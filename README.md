# HR Employee Attrition Analysis

## 📌 Project Overview

This project analyzes employee attrition to explore workforce trends and identify factors associated with employees leaving an organization.

The analysis uses Python for data cleaning and exploratory data analysis (EDA), SQL for querying business data, and Power BI for interactive dashboard development.

## 🎯 Business Objectives

- Understand overall employee attrition.
- Explore attrition patterns across employee demographics and job-related factors.
- Compare attrition across relevant workforce categories.
- Identify patterns that may help HR teams investigate employee retention.
- Present findings through an interactive Power BI dashboard.

## 🛠️ Tools & Technologies

- **Python:** Pandas, NumPy, data cleaning, exploratory data analysis.
- **SQL:** Data querying, filtering, joins, and aggregations.
- **Power BI:** KPI cards, visualizations, and interactive dashboard reporting.

## 📂 Project Structure

The project will be organized into the following sections:

- `python/` — Data cleaning and exploratory data analysis.
- `sql/` — SQL queries used for business analysis.
- `power-bi/` — Dashboard file and screenshots.
- `README.md` — Project documentation and key findings.

## 🔎 Analysis Workflow

1. Understand the dataset and its structure.
2. Inspect data types, missing values, and data quality.
3. Perform data cleaning and exploratory data analysis using Python.
4. Analyze workforce patterns using SQL.
5. Build a Power BI dashboard to communicate key metrics and findings.
6. Summarize business insights and practical recommendations.

## 📊 Dataset

The analysis uses an employee attrition dataset containing workforce information.

**Dataset size:** 1,470 rows and 35 columns.

The dataset includes employee attributes and an attrition indicator. The original dataset source and any applicable sharing restrictions will be documented when the dataset is added.

## 💡 Key Findings

Key findings will be documented after the final Python, SQL, and Power BI results have been reviewed and verified.

## 📌 Business Recommendations

Recommendations will be based on the verified analysis findings. Observed associations will not be presented as proof of causation.
